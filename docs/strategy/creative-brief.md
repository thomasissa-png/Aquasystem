## 1. Positionnement en une phrase

> **"De la vision à la réalisation — eau, jardin, propriété — un seul interlocuteur, aucun compromis."**

Tout ce qui est produit (texte, image, parcours, contenu) doit pouvoir se justifier par cette phrase.

---

## 2. Promesse résumée

**Ce que la marque fait** : elle transforme une belle propriété de l'ouest parisien en espace de vie complet, en portant seul la vision eau et végétal de la conception à la réalisation, sans que le propriétaire ait à coordonner quoi que ce soit.

**Ce que la marque ne fait pas** : voir section INTERDITS ci-dessous.

---

## 3. Cibles

### Cible principale : Alexandre
45-60 ans, capital élevé, propriétaire 78/92. Veut un partenaire de confiance, pas un prestataire. Son vocabulaire : "propriété", "projet", "quelqu'un qui comprend". Il ne dit jamais "devis gratuit". Voir personas.md pour le détail complet.

### Cible secondaire : Camille (architecte/prescripteur)
Architecte ou architecte paysagiste, prescrit les exécutants à ses clients haut de gamme. Cherche un partenaire qui protège sa réputation. Son vocabulaire : "cahier des charges", "délai de réalisation", "référence vérifiable".

## 7. Références d'univers visuel

**Registre cible :** magazines d'architecture résidentielle premium (AD Architectural Digest, Côté Maison haut de gamme), hôtels de charme 5 étoiles campagne française, domaines viticoles de prestige.

**Palette indicative :** tons terreux et minéraux (pierre, ardoise, terre, lin, vert profond foncé) + éclats d'eau (reflets, lumière rasante). Éviter les bleus piscine saturés type chlore.

**Photographie :** photos réelles des réalisations (source : book Calameo + site aqua-system.fr existant). Lumière naturelle de fin de journée, propriétés dans leur contexte végétal. Zéro photo de banque d'images générique (piscine de villa anonyme, jardin type catalogue).

**Typographie (indication) :** registre sobre à empattement discret pour les titres (type : serif moderne, pas de sans-serif corporate) + sans-serif sobre et lisible pour les corps de texte. Ne pas décider avant le brief design complet — indication de registre seulement.

## 8. INTERDITS absolus

### Interdits visuels

| Interdit | Raison |
|----------|--------|
| Photos de banque d'images génériques (villa anonyme, jardin Pinterest) | Déscrédibilise la promesse de réalisme et d'ancrage local |
| Piscines aux couleurs saturées de type publicité low-cost | Contre-positioning bling-bling incompatible avec le registre sobre |
| Fonds dégradés, effets de lumière artificielle, overlays de couleur | Registre promotionnel incompatible |
| Logos partenaires en première ligne (Esprit Piscine, Socotec) au-dessus du pli | Les certifications sont des preuves, pas la signature — les intégrer discrètement |
| Emojis | Incompatible avec le ton sobre |
| Animations agressives, parallax excessif, scroll-jacking | Nuisent à l'expérience perçue comme sérieuse |

### Interdits copy

| Interdit | Raison |
|----------|--------|
| "Devis gratuit" / "Offre spéciale" / "Promo" | Registre discount — contre-positioning |
| "Le meilleur pisciniste de..." / "N°1 en..." | Superlatif non étayé — crédibilité nulle pour la cible |
| "Équipe passionnée" / "Au service de vos rêves" | Phrases creuses utilisées par tous les concurrents — zéro différenciation |
| Jargon technique brut sans traduction (pH, NTU, m³, ORP) | Réservé aux supports techniques SAV — pas dans le site vitrine |
| Faux témoignages / verbatims inventés | Règle anti-fictif absolue (CLAUDE.md) |
| "Nos deux sociétés" ou formulation impliquant une propriété juridique commune | L'acquisition des Terres Essentielles n'est pas actée — formulation autorisée : "deux maisons réunies autour d'une même vision" |
| Affirmation "société créée il y a 30 ans" | La SARL Aqua System date de 2021 — dire "plus de 30 ans d'expertise" (la marque, pas la SARL) |
| Mentions de concurrents par nom | Règle CLAUDE.md n°9 — jamais dans les livrables client-facing |

### Interdits UX / parcours

| Interdit | Raison |
|----------|--------|
| Popup de capture dès l'arrivée | Rupture de confiance immédiate pour la cible Alexandre |
| Formulaire de devis en sticky bar | Registre commercial pressant incompatible |
| Urgence artificielle ("Plus que 3 places !") | Incompatible — la cible détecte immédiatement les techniques de manipulation |
| Chatbot automatique | Promet une relation humaine que l'outil ne peut pas tenir |
| Bouton CTA "Demandez un devis" | Remplacer par "Parlez-nous de votre projet" ou "Décrivez votre projet" |

## 9. OBLIGATIONS

### Obligations contenu

| Obligation | Justification |
|------------|---------------|
| Preuves factuelles non-négociables : 30+ ans, 350 piscines entretenues, Socotec, L'Esprit Piscine | Ces proof points doivent apparaître sur le site — pas optionnels |
| Photos réelles des réalisations uniquement | La promesse "ancrage local, réalisations réelles" est portée par les images — elles doivent être authentiques |
| Mention des deux maisons : "Aqua System" et "Les Terres Essentielles" | L'architecture ombrelle doit être lisible pour le cross-selling |
| Formulaire de contact avec champ "votre projet" (texte libre) | Qualification douce — pas de menu déroulant forcé |
| Mention légale deux entités distinctes | Obligatoire — à finaliser après acquisition LTE |
| Section ou mention spécifique pour les prescripteurs architectes | Cible secondaire à fort potentiel — ne pas l'oublier dans le parcours |

### Obligations UX

| Obligation | Justification |
|------------|---------------|
| CTA principal = contact projet, pas devis | Vitrine conviction-first — la conversion est un contact qualifié, pas une vente en ligne |
| Portfolio / réalisations = section centrale (pas secondaire) | Vecteur de conviction principal identifié dans brand-platform.md |
| Architecture i18n-ready (FR + EN prévu) | Décision fondateur validée — scope technique à prévoir dès la V1 |

## 10. Parcours conviction-first (vitrine, pas funnel)

```
Découverte (Awareness)
  → Première impression : propriété réelle, vision globale
  → Pas de CTA agressif au premier écran

Crédibilité (Considération)
  → Portfolio de réalisations locales (photos réelles)
  → Preuves : ancienneté, certification, réseau
  → Les deux expertises maison visibles

Confiance (Décision)
  → Section "comment ça se passe" (process simple, humain)
  → Formulaire ouvert : décrivez votre projet
  → Pas de formulaire à qualification forcée en amont
```
