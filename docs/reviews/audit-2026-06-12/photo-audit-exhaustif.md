## PARTIE 2 — JUGEMENT /10 PAR EMPLACEMENT

Méthode : photo lue visuellement + screenshot de rendu lu. Note dans le contexte de l'emplacement (cadrage au ratio rendu, ce qu'elle évoque à cette taille, cohérence message). Une photo bonne en hero peut être faible en carré.

### A. Accueil (/) — CAS PRIORITAIRE

#### A1. Hero — `piscine-couloir-demeure-ancienne` — VERROUILLÉ FONDATEUR

**Note : 10/10.** Approuvé. Ne pas toucher. La demeure haussmannienne, le bassin miroir, la lumière franche, le ciel bleu — c'est exactement la promesse. Référence pour juger tout le reste.

#### A2. Bloc Aqua System — `piscine-terrasse-bois-plongee` — format carré 1:1

Photo vue : vue aérienne plongeante sur bassin rectangulaire + grande terrasse bois + pelouse + végétation.

**Diagnostic dans ce format carré :**

En 1:1, le cadrage `object-center 40%` retient le bassin + la terrasse bois dans la zone centrale. La composition est propre mais le problème est structurel : la vue en plongée frontale aplatit l'espace. Dans ce carré, on voit une terrasse vue de dessus et un bassin — c'est une photo de catalogue de pisciniste, pas une image d'identité de maison. L'absence de propriété (bâtiment, façade, architecture) est criante en regard du hero juste au-dessus qui montre une demeure imposante. Le passage hero → bloc Aqua System est un choc vers le bas : on descend d'une propriété de caractère à une terrasse en bois standard.

Rendu mobile (gate-shots home-s01) : le carré en pleine largeur. La terrasse bois avec deux transats en bois blanc et les chaises de jardin colorées (cyan, rouge-orange) au fond — exactement le type de détail bling/décontracté que le projet définit comme "ce que nous ne sommes pas" (3 mots négatifs : bling-bling, standardisé).

**Note : 4/10 dans ce contexte.**

Raisons de l'échec : (1) vue de dessus = pas d'identité d'entreprise, juste un produit ; (2) les chaises colorées cassent le registre premium-sobre ; (3) aucune propriété visible = manque de contexte "belle demeure de l'ouest parisien" ; (4) au format carré la composition se réduit à "bois + eau" sans profondeur narrative.

Décision : **REMPLACER** (voir §3 pour options).

#### A3. Bloc Les Terres Essentielles — `jardin-bassin-maison-bois` — format carré 1:1

Photo vue : maison contemporaine à bardage bois, bassin de nage long, terrasse bois avec grande table, bambous en fond, ciel bleu estival.

**Diagnostic dans ce format carré :**

La photo est cadrée `object-center 30%` en carré — on retient le haut de la composition : la maison bois, les bambous, le ciel. Le bassin passe partiellement hors cadre. Ce cadrage expose directement le problème : la maison à bardage bois est très générique (Leroy Merlin catalogue 2023), les bambous sont communs, et surtout ce n'est PAS un jardin réalisé par Les Terres Essentielles — c'est une photo de réalisation piscine (jardin-bassin, slug type projet_complet). Utiliser cette photo pour représenter "Les Terres Essentielles / Jardins & Paysage" est éditoralement malhonnête : on montre une maison contemporaine de style Hauts-de-Seine quelconque, pas un jardin de prestige réalisé par un bureau d'études paysager.

En rendu mobile (gate-shots home-s02) : on voit très nettement la grille de jardin en métal (panneau d'oiseau décoratif en bas à gauche), la grand table de jardin plastifiée — précisément les éléments qui font "jardin de maison individuelle ordinaire", pas "parc de propriété de l'ouest parisien". Les bambous connotent "jardin contemporain discount" dans l'esprit du persona Alexandre qui connaît les matériaux.

**Note : 3/10 dans ce contexte.**

Raisons de l'échec : (1) maison bois générique, pas une propriété de caractère ; (2) la photo est une réalisation piscine présentée comme réalisation jardin = tromperie éditoriale ; (3) détails (table plastique, oiseau décoratif, bambous communs) incompatibles avec le positionnement ; (4) en carré, le cadrage tombe sur les parties les moins premium de la photo.

Décision : **REMPLACER** (voir §3 pour options, option typographique incluse).

### 3b. Option TYPOGRAPHIQUE SANS PHOTO — composition premium

L'alternative honnête quand le stock ne convient pas. Beaucoup de maisons de prestige n'utilisent PAS de photo dans leurs blocs d'identité — la typographie est la photo.

**Esquisse de composition pour les deux blocs (grid 2 colonnes conservée) :**

```
Bloc gauche — Aqua System
┌─────────────────────────────────────┐
│ fond : sand-950 (quasi-noir)         │
│                                      │
│  ──────────                          │
│  AQUA SYSTEM                         │  ← text-xs tracking-[0.2em] sand-300/60
│                                      │
│  Piscines                            │  ← DM Serif Display, 3.5rem, sand-100
│  & Bien-être                         │
│                                      │
│  monogramme AS graphique ?           │  ← optionnel, trait fin
│  ou filet horizontal 1px sand-700    │
│                                      │
└─────────────────────────────────────┘

Bloc droit — Les Terres Essentielles
┌─────────────────────────────────────┐
│ fond : forest-950 ou #1A2A1A         │
│                                      │
│  ──────────                          │
│  EN PARTENARIAT AVEC                 │  ← text-xs tracking-[0.2em] green/60
│  LES TERRES ESSENTIELLES             │
│                                      │
│  Jardins                             │  ← DM Serif Display, 3.5rem, sand-100
│  & Paysage                           │
│                                      │
│  filet vert-forêt 1px                │
│                                      │
└─────────────────────────────────────┘
```

**Avantages de l'option typographique :**
- Pas de photo médiocre — zéro risque d'un 3ème rejet
- Cohérente avec le système de design (backgrounds sombres déjà dans la palette)
- La différenciation eau (bleu-slate foncé) / végétal (vert foncé) est immédiatement lisible
- Les maisons de luxe qui n'ont pas de photos de qualité et font ce choix ont raison : Bottega Veneta, Baccarat, certains architectes-paysagistes parisiens utilisent exclusivement la typo
- Le bloc devient un "tableau typographique" — c'est une composition qui dit "maison" pas "catalogue"
- Techniquement simple : supprimer le `<Image>` et rendre un `<div>` avec le fond et la typo

**Inconvénient :** l'accueil perd 2 photos dans la section clé juste sous le hero. Pour un site dont le portfolio est la force, c'est un choix à assumer.

**Verdict : l'option typographique est plus forte que toute photo du stock pour le bloc LTE** (aucune photo jardinerie n'atteint 5/10 en carré). **Pour le bloc Aqua System, `piscine-interieure-pierre-poutres` reste viable si le fondateur accepte l'intérieur.**
