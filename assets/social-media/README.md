# Assets social media — jardinerie Les Terres Essentielles

Photos fournies par le fondateur (Nicolas Berg) le **2026-06-12**, issues de la
page Facebook **Les Terres Essentielles** (https://www.facebook.com/LesTerresEssentielles/).

## Statut

- **Droits** : accord global d'utilisation accordé par le fondateur le 2026-06-12
  (project-context.md → « Validations fondateur (2026-06-12) »).
- **Usage** : réseaux sociaux / communication **uniquement**. Ces fichiers ne
  sont **PAS** intégrés au site (hors `public/`, jamais shippés dans le build
  statique). Registre « point de vente / saisonnier / boutique » non aligné sur
  le positionnement premium du site umbrella.
- **Nature** : toutes montrent la **jardinerie** (point de vente, étals, boutique)
  — **jamais** une réalisation paysagère. Ne pas présenter comme preuve de
  création de jardin.

### Réserve ajoutée le 2026-06-12 (lot photos jardins fondateur)

Trois des six photos jardins fournies ce jour relèvent du registre social, pas du
site premium : `bananiers-serre-jardinerie` (serre jardinerie), `fleurs-blanches-macro`
(macro fleurs) et `rosiers-jardin` (rosiers). Optimisées JPEG ≤ 1900px (script :
`scripts/build-jardins-fondateur-images.mjs`). Les 3 autres (terrasses plongeante,
massif exotique escalier, massif palmier/agaves) sont des créations paysagères :
intégrées au site dans `public/images/realisations/`.
